## AI模型

- **[NVIDIA 开源 Nemotron-Labs-Image-30B-A3B 图像生成模型](https://huggingface.co/nvidia/Nemotron-Labs-Image-30B-A3B)**

  NVIDIA 在 Hugging Face 放出 Nemotron-Labs-Image-30B-A3B 的开源权重，它是 Nemotron-Labs-VisualCreation（Pixel as Code）框架中的自回归图像生成组件。模型为 30B 总参数、3B 激活的 MoE（Nemotron-H 混合 Mamba-2 与注意力），由 Nemotron 3 Nano 初始化并经渐进式中训练与 GRPO 训练。据称其在关键基准上超过 GPT Image 2 与 Nano Banana Pro。

## 新产品项目

- **[Carry：把 AI 对话备份为本地 Markdown](https://carry.md/)**

  Carry 可将 ChatGPT、Claude、Gemini、Grok 的历史对话导出并以 Markdown 保存到用户自己的文件夹，支持搜索与跨会话继续。它定位为把 AI 聊天记录真正归用户所有的备份与检索工具。

- **[Openfal：本地 fal 兼容的图像/视频扩散推理服务](https://openfal.org)**

  Openfal 提供一条命令即可在本机（Windows、Linux、macOS）搭建与 fal API 兼容的图像与视频扩散推理服务。它可本地运行 Qwen-Image-2.1、Wan 2.2、MiniMax H3 等模型，无需手动搭建 ComfyUI 节点图。

- **[Rustling：面向 Apple Silicon 的 Rust AI Agent 与推理引擎](https://github.com/onatm/rustling)**

  Rustling 是一个用 Rust 编写的 AI agent，内置面向 Apple Silicon 的 Inkling 2 Mini 推理引擎。它把 agent 逻辑与本地推理打包在一起，方便在 Mac 上本地运行。
