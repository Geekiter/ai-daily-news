## agent 设计论文

- **[Real2SimLab: A Unified Platform for Real-to-Simulation Transfer](https://huggingface.co/papers/2611.34849)**

  研究问题：real-to-simulation 研究（即由视频生成仿真程序）中，每个基准各自定义输入、交付物与评分流程，导致在 N 个方法和 M 个基准之间进行评测时产生 N×M 次集成。该论文提出统一平台 Real2SimLab：对每个方法，先运行其编码 agent 生成的程序，再直接调用各基准自带的评分器为输出仿真打分；同时提供一条用于构建训练数据和奖励标注的流程，并通过过滤基准中已有的视频来避免数据污染。平台已支持 47 个编码 agent、5 个非 agent 方法和 6 个基准，并附带收录近 300 篇论文的研究地图 Awesome-Real2Sim。论文发表于 arXiv（预印本，HF Daily Papers 2026-11-26）。

- **[VibeVideoAgent: Closing the Perceptual Loop for Code-Driven Video Generation](https://huggingface.co/papers/2611.34237)**

  研究问题：由编码 agent 编写并运行渲染程序（code-driven video generation）时，程序即使正常退出，仍会出现标签重叠、镜头偏移、音频不同步等运行时不会报错的缺陷；若把渲染的帧和音频直接反馈给编码 agent，会撑爆长程上下文，而只评审最终完整渲染则代价过高。该论文提出免训练框架 VibeVideoAgent，让编码 agent 在制作过程中持续检查草稿：把多模态感知隔离在短生命周期上下文中，并以七种原语在统一的多时钟表示上做粗到细的探索、基于证据的核对与局部信号测量，同时用分阶段协议先在最小预览上测试风险最高的决策。在 VibeVideoBench 全部 239 个任务上，该框架在 Claude Opus 5.5、GPT-6 Astra、Claude Sonnet 5.5 三种运行时提升了整体视听质量（L3），在不增加运行开销的情况下，分别最多提升 0.40、0.24、0.13，音画同步提升最多 +0.56。论文发表于 arXiv（预印本，HF Daily Papers 2026-11-26）。

- **[When Every Rollout Fails: Splicing Learner-Conditioned Options into Long-Horizon Agent RL](https://huggingface.co/papers/2611.34777)**

  研究问题：基于可验证奖励的组相对强化学习在长程 agent 任务上容易遇到“全失败组”——同组所有轨迹奖励均为 0，无法得到基于奖励的策略梯度；而用更强模型提供完整轨迹作为补救又昂贵，并且会让学习者接触很长的离策略历史。该论文提出 SPLICE：对于每个全失败组，在线地从当前策略轨迹中选出一个拼接点，并生成若干有界 option，通过重复当前策略的续写来估计每个 option 的价值，再把正向估计转化为按回报加权的局部训练目标。在 SWE-bench Verified 与 BrowseComp-Plus 两个长程任务的两类策略模型上，SPLICE 均优于 GRPO 和完整轨迹引导基线，较 GRPO 提升 2.8–9.8 个百分点，并将初始失败的 SWE 任务通过率提升 10.8 个百分点。论文发表于 arXiv（预印本，HF Daily Papers 2026-11-26）。
