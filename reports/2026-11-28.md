## github 热门项目

- **[google-labs-code/stitch-skills](https://github.com/google-labs-code/stitch-skills)**

  Google Labs 的 Stitch Skills 库为 Stitch MCP 提供 agent 技能，并遵循 Agent Skills 开放标准。项目可与 Antigravity、Gemini CLI、Claude Code 和 Cursor 等编码工具配合使用。

- **[n8n-io/nod](https://github.com/n8n-io/nod)**

  n8n 开源个人电脑 agent，可在真实网站上处理账单、准备会议和取消试用等任务，并在执行前征求确认。项目支持本机运行和用户自选模型。

- **[alibaba/open-code-review](https://github.com/alibaba/open-code-review)**

  阿里开源混合式代码审查工具，将确定性规则流水线与 LLM agent 结合，提供逐行评论及多语言安全规则。它兼容 OpenAI 和 Anthropic 接口，适合关注 AI 代码审查落地的开发者。
